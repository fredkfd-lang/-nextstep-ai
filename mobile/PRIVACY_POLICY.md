# BerOpp – Privacy Policy (Draft)

**Last updated:** 24 September 2026

BerOpp is an application for jobs, Ausbildung, applications and career opportunities.

## 1. Data we may process

Depending on the features a person uses, BerOpp may process:
- email address and authentication information;
- name, phone number and city/address entered in the profile;
- saved jobs and application information;
- CV files in PDF format, when CV upload is enabled;
- employer information such as company name and website;
- job and Ausbildung information published through the app.

## 2. Why data is used

Data is used to:
- create and secure user accounts;
- show and save jobs and Ausbildung opportunities;
- allow candidates to submit and track applications;
- allow employers to publish opportunities and manage applications;
- provide profile and CV functionality.

## 3. Firebase

BerOpp uses Firebase services for authentication, database functionality and, when enabled, file storage. Firebase is provided by Google.

The production version should link to the applicable Firebase/Google privacy information and should document the final hosting, retention and processing configuration before store submission.

## 4. CV files

When CV upload is enabled, the user chooses the PDF file to upload. The file is associated with the user's BerOpp account and is intended to support applications.

CV upload is optional. The current mobile project keeps the upload code prepared, but Firebase Storage requires a billing-enabled Firebase project before this feature can be used in production.

## 5. User choices and rights

Users should be able to access, correct or request deletion of their personal information, subject to applicable law and legitimate retention requirements.

Before publishing this policy as the production policy, BerOpp should provide a working contact address for privacy requests and confirm the final retention/deletion process.

## 6. Children

BerOpp is intended for people seeking jobs, Ausbildung and career opportunities. It is not designed as a service for children.

## 7. Changes

This policy may be updated when BerOpp adds features or changes its data processing.

## Production note

This document is a draft for the BerOpp project. It should be reviewed and completed with the final legal entity/contact details, retention periods, processor information and production URLs before submitting the app to Apple or Google.
