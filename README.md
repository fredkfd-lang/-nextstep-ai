# BEROPP

BEROPP is a career-support web app for Ausbildung, jobs, CV creation and application preparation.

## Current direction

- German and English language support
- Firebase authentication
- CV/profile support
- Ausbildung and job discovery
- Future PDF CV upload and application assistant

## Development plan

1. Preserve the existing working application.
2. Review and separate the current single-page code into maintainable modules.
3. Add secure CV PDF upload using Firebase Storage.
4. Add authenticated dashboard and saved applications.
5. Prepare a responsive mobile experience for future iOS and Android packaging.

Never place Firebase private keys or other secrets directly in the repository. Use environment variables for local development and deployment configuration.
